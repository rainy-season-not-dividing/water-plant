Water Plant Windows Release

How to run:
1. Double-click start-water-plant.bat.
2. The browser should open http://127.0.0.1:8000 automatically.
3. Keep the water-plant.exe console window open while using the app.

Configuration:
- Edit .env in this folder if API keys or model settings need to change.
- APP_PORT can be set before starting if port 8000 is occupied.

Files:
- water-plant.exe is the packaged backend.
- The frontend build is bundled into the executable package and served by the backend.
- .env.example shows available environment variables.
